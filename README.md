# Dungeon Loot

Небольшое полностью локальное desktop-приложение для выдачи лута по результату физического броска d20. Интерфейс сделан на Python 3 и `tkinter/ttk`; интернет, браузер, сервер и LLM во время работы не нужны.

## Уровни лута

- 1–10 — бытовые вещи: от мусора до дорогих изделий ремесленников.
- 11–15 — снаряжение приключенца, оружие, броня и мастерские инструменты.
- 16 — переходный tier с редкими и необычными магическими вещами.
- 17 — хороший магический лут.
- 18 — сильные магические предметы.
- 19 — очень редкие и желанные, но не артефактные вещи.
- 20 — исключительно ценный обычный, мастерской или магический non-artifact лут.
- 20 + lucky — джекпот: официальный D&D-артефакт из отдельного пула.

## Запуск из исходников

Требуется Python 3.11+ с поддержкой Tk.

```powershell
python main.py
```

## Проверки

```powershell
python -m unittest discover -s tests -v
python tools/validate_dataset.py
```

Тесты проверяют объём и поля базы, уникальность, распределение, баланс цен, семантические группы, выбор предметов, валидацию ввода и pity-механику. Отдельные инварианты гарантируют, что артефакт не может выпасть без lucky-двадцатки.

## Сборка Windows exe

Запустите:

```bat
build.bat
```

Сценарий устанавливает PyInstaller, выполняет тесты и создаёт `dist\DungeonLoot.exe` без консольного окна. Оба CSV включаются в standalone-файл через `dungeon_loot.spec`.

## Данные

- `data/items.csv` — 1645 обычных предметов: по 80 для каждого roll 1–19 и 125 для roll 20. Файл сохранён в UTF-8 с заголовком и пригоден для ручного редактирования.
- `data/artifacts.csv` — 13 официально названных артефактов D&D 5e. Поле `polarity` оставлено как справочное и не влияет на выбор джекпота.

После ручного изменения CSV запустите тесты и валидатор. `id` должен оставаться уникальным, цены — положительными, lucky-цена обычного item — не ниже normal-цены. `tools/generate_dataset.py` и `tools/rebalance_catalog.py` используются только для development-материализации готового CSV; runtime ничего не генерирует.

## Lucky / pity

Первый успешный запрос имеет скрытый шанс 1%. После каждой неудачи шанс повышается на один процентный пункт; после удачи сбрасывается до 1%. Проверяется шанс до повышения, поэтому первая неудача превращает 1% в 2% только для следующего запроса. При 100% lucky гарантирован.

Для значений 1–19 lucky использует улучшенную версию той же записи и сохраняет тему исходного предмета. Для 20 обычный результат выбирается из `items.csv`, а lucky-результ сразу — из всего `artifacts.csv`, без промежуточного выбора item.

Состояние не показывается в интерфейсе и хранится здесь:

- Windows: `%LOCALAPPDATA%\DungeonLoot\state.json`
- macOS: `~/Library/Application Support/DungeonLoot/state.json`
- Linux: `$XDG_STATE_HOME/dungeon-loot/state.json` или `~/.local/state/dungeon-loot/state.json`

Повреждённое или некорректное состояние автоматически заменяется безопасным значением 1%.

## Источники названий артефактов

Названия сверены по официальному каталогу D&D Beyond и открытой SRD 5.1. В CSV хранятся ссылки и названия книг-источников; описания и оценочные цены написаны специально для приложения и не воспроизводят официальные тексты.
