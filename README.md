# Dungeon Loot

Небольшое полностью локальное desktop-приложение для выдачи лута по результату физического броска d20. Интерфейс сделан на Python 3 и `tkinter/ttk`; интернет, браузер, сервер и LLM во время работы не нужны.

## Запуск из исходников

Требуется Python 3.11+ с поддержкой Tk.

```powershell
python main.py
```

## Проверки

```powershell
python -m unittest discover -s tests -v
python tools/validate_dataset.py
```

Тесты проверяют объём и поля базы, уникальность, распределение, рост медианных цен, выбор предметов, оба пула артефактов, валидацию ввода и pity-механику.

## Сборка Windows exe

Запустите:

```bat
build.bat
```

Сценарий устанавливает PyInstaller, выполняет тесты и создаёт `dist\DungeonLoot.exe` без консольного окна. CSV включаются внутрь standalone-файла через `dungeon_loot.spec`.

## Данные

- `data/items.csv` — обычные предметы для значений 1–19. Файл сохранён в UTF-8 с заголовком и пригоден для ручного редактирования в табличном редакторе.
- `data/artifacts.csv` — официально названные артефакты D&D 5e для значения 20. `GOOD` используется при lucky-срабатывании, `DANGEROUS` — при обычном результате.

После ручного изменения CSV запустите тесты и валидатор. `id` должен оставаться уникальным, цены — положительными целыми числами, а каждый обычный уровень — содержать не менее 55 строк.

## Lucky / pity

Первый успешный запрос имеет скрытый шанс 1%. После каждой неудачи шанс повышается на один процентный пункт; после удачи сбрасывается до 1%. Проверяется шанс до повышения, поэтому первая неудача превращает 1% в 2% только для следующего запроса. При 100% удача гарантирована.

Для значений 1–19 lucky использует улучшенную версию той же записи и сохраняет тему исходного предмета. Для 20 обычный результат берётся из опасного/неоднозначного пула официальных артефактов, lucky — из положительного/ценного.

Состояние не показывается в интерфейсе и хранится здесь:

- Windows: `%LOCALAPPDATA%\DungeonLoot\state.json`
- macOS: `~/Library/Application Support/DungeonLoot/state.json`
- Linux: `$XDG_STATE_HOME/dungeon-loot/state.json` или `~/.local/state/dungeon-loot/state.json`

Повреждённое или некорректное состояние автоматически заменяется безопасным значением 1%.

## Источники названий артефактов

Названия сверены по официальному каталогу D&D Beyond и открытой SRD 5.1. В CSV хранятся ссылки и названия книг-источников; описания и оценочные цены написаны специально для приложения и не воспроизводят официальные тексты.
